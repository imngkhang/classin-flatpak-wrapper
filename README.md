# Classin unofficial Flatpak wrapper

## Description

This is the unofficial Flatpak wrapper for ClassIn application, because Classin official cilent only provides .deb files (Which cannot install on Red Hat, SUSE, Arch, Gentoo based or immutable systems). This wrapper is create by downloading the .deb files and extract them in the sandbox directly when installing.

## ⚠️ Bug and Issues
  - **Can't share screen on Wayland:** This is a issue from EEO, because they don't implement the libqwayland.so on the cilent yet, so screen sharing will not work (oleaving only behind a black screen.)
  
  If you encounter any issues, please report in [GitHub issues](https://github.com/imngkhang/classin-flatpak-wrapper/issues)
